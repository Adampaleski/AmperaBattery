Top-down, front to the left, passenger (right) side at the top. Model units are inches from the published Teryx 750 dims (ASSUMED) — every length is ESTIMATED until one tape measurement is entered above. Drag blocks (boxes carry what is inside them; run ends follow their terminals), drag a run's bends, or the whole run. Window: drag left→right to pick what is fully inside, right→left to pick what it touches; drag the picked set to stretch. Right-click or long-press a run to add a bend, a bend to delete it. Pinch or scroll to zoom, drag the background to pan. Edits stay in this browser (localStorage) until you Export JSON and commit it as docs/layout/teryx.layout.json; scripts/check_layout.py runs the same check as this page.
