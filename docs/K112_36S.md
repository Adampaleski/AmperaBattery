# 36S — two KICMs on one daisy chain

## Hardware

- **BICM-A (K112)**: 24S — tap Teensy on X1 pins 9–13 (toward BECM).
- **BICM-B (12S)**: daisy out from A (pins 14–18 → next module 9–13).
- One **125 kbps** CAN tap sees both modules.

## Firmware

```bash
pio run -e teensy41_k112_36s -t upload
pio device monitor -b 115200
```

Expect **`cells=36 stable=Y`** and **`bicms=2/2`**.

Default CAN mapping (change in `include/BicmPackProfile.h` if your bus differs):

| BICM | IDs | Cells |
|------|-----|-------|
| A | `0x460` / `0x470` | 1–24 |
| B | `0x461` / `0x471` | 25–36 |

After wiring B, run **`s`** (ID histogram). If B uses other IDs, edit `kBicmStreams` and rebuild.

## Not included

This build still does **not** send balance (`0x300`) or charge commands. See `docs/SAFETY.md`.
